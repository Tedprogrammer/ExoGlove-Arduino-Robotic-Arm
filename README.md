# ExoGlove Arduino Robotic Arm

An intuitive gesture-controlled robotic arm driven by an Arduino micro-controller and a 3D-printed wearable exohand glove.

## 🚧 Project Status: Active Development
- **Hardware:** Mechanical build complete.
- **Current Stage:** Motor response tuning, sensor mapping, and Arduino driver code development.

## ⚙️ Features & Components
- **Glove Control:** Flex sensors / potentiometers mounted on 3D-printed exohand structure.
- **Arm Actuation:** Servo motors powered by Arduino.
- **3D Printing:** Custom STL components printed for ergonomic glove fit.
